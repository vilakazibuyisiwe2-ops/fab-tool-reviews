# 🔧 Fab & Tool Reviews

Honest tool, safety gear and workshop reviews for artisans and tradesmen, written by a qualified boilermaker who actually works with metal.

🌐 **Live site:** https://vilakazibuyisiwe2-ops.github.io/fab-tool-reviews/

## What's on the site

- **Reviews**: welding equipment, fabrication tools, safety gear and CAD software
- **Blog**: protective gear tips, how-to drawings, and life off the clock for artisans
- **Safety guides & education**: free, practical guides for the workshop

## Project structure

- `_posts/`: blog posts
- `_reviews/`: product reviews (Jekyll collection)
- `_educational/`: safety guides and education
- `_layouts/`: page layouts
- `assets/`: images and styles
- `_config.yml`: site settings, plugins and collections
- `index.md`, `about`, `contact`, `affiliate-disclosure`, `privacy-policy`: core site pages

## Built with

Jekyll, the Minima theme, and GitHub Pages, with `jekyll-feed`, `jekyll-sitemap` and `jekyll-seo-tag`.
